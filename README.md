# 😌RESTEasy
Desktop app for Windows machine for testing requests on any REST API's.

## 🛠️Technologies
- ``Windows Presentation Foundation (WPF)``
- ``.NET 10``
- ``Nunit``

## ⚙️Features
- Multiple request types available
- Sending requests with JSON, XML, plain text or empty body
- Status code response with response time in milliseconds
